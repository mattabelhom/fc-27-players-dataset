# EA SPORTS FC 27 Players Dataset

Complete EA SPORTS FC 27 players dataset featuring all base players, including their ratings, attributes, and detailed stats.

The dataset was extracted from [FIFPlay's FC 27 Players Database](https://www.fifplay.com/fc-27/players/) on October 11, 2026.

## Dataset Overview

This dataset contains player data from EA SPORTS FC 27, including:

- Player names and overall ratings
- Player positions and preferred foot
- Clubs, leagues, and nationalities
- Pace, shooting, passing, dribbling, defending, and physical attributes
- Detailed individual player attributes and stats
- Additional player information

## Dataset Uses

The dataset can be used for:

- Football player analysis and comparisons
- Data science and machine learning projects
- Player ratings and attributes research
- Data visualization
- Football statistics and analytics
- Building player comparison tools and applications
